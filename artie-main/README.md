# ARTIE

This is the source code behind Artie, my answer to the question:

> "Everyone chats with AI through their phone or computer, why not a CRT TV instead?"

I made this purely to play around with the concept of getting a rudimentary AI assistant working from scratch and to use vanilla JavaScript and HTML elements to display a kind of 'avatar' on a vintage screen. This project was all for fun, so don't take it too seriously or expect many updates.

If you'd like to run this yourself, you can use the following instructions:

1. Clone this repo
2. Run `npm install && npm run dev` to get a local server up for it
3. Visit `http://localhost:5173` and open up your console
4. Input your OpenAI API key and start talking!
